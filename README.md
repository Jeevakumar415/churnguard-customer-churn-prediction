# ChurnGuard - Customer Churn Prediction

ChurnGuard is a machine learning project that predicts whether a customer is likely to churn based on customer account and service-related information.

The project follows a complete machine learning workflow:

**Explore → Clean → Train & Evaluate → Predict**

The project uses **Logistic Regression** to classify customers into two categories:

- **Likely to STAY**
- **Likely to CHURN**

---

## Project Overview

Customer churn is an important business problem where companies need to identify customers who may stop using their services.

ChurnGuard processes customer data, performs data cleaning and preprocessing, trains a Logistic Regression model, evaluates its performance, and provides a simple prediction interface for new customers.

---

## Objectives

- Explore the customer churn dataset
- Identify missing values and duplicate records
- Clean and preprocess the dataset
- Convert categorical data into machine-learning-compatible features
- Train a Logistic Regression model
- Evaluate the model using accuracy and classification metrics
- Predict whether a customer is likely to churn
